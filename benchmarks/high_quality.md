# 基准案例库 — 高质量案例

## BM-003

| 属性 | 值 |
|------|-----|
| 案例编号 | BM-003 |
| 分类 | high_quality |
| 案由 | 合同纠纷 |
| 关键异常 | 无 |
| 预期等级 | 低度异常 |

**摘要**：法院对双方提交的证据逐一评述，对不采信的证据说明了理由，争议焦点归纳完整，法律适用准确，说理充分，审限合规。唯一可议之处为自由裁量金额略高于类案均值但仍在合理区间。

**推理**：无A系列异常触发，裁量幅度在正常范围内（Deviation Score < 0.5），判定为低度异常（仅1-2个孤立微弱信号）。

## BM-004

| 属性 | 值 |
|------|-----|
| 案例编号 | BM-004 |
| 分类 | high_quality |
| 案由 | 劳动争议 |
| 关键异常 | 无 |
| 预期等级 | 低度异常 |

**摘要**：法院对劳动合同解除的合法性进行了完整的三段论论证，证据采信标准一致，举证责任分配正确，经济补偿金计算有明确法条依据和计算过程。

**推理**：各项检测均未触发异常，为高质量判决的标杆案例。
