# 基准案例库 — 边界案例

## BM-005

| 属性 | 值 |
|------|-----|
| 案例编号 | BM-005 |
| 分类 | borderline |
| 案由 | 侵权责任纠纷 |
| 关键异常 | A3, A7 |
| 预期等级 | 中度异常 |

**摘要**：法院适用了公平责任原则而非过错责任原则，但说理部分较为简略。判决书部分段落呈现模板化特征，但核心争议焦点有回应。法律适用虽有争议空间但并非明显错误。

**推理**：A3（法律适用未充分解释）+ A7（模板化论证）两个异常，但严重度较低，且指向不一致（A3可能因法官业务能力，A7为常见现象），判定为中度异常。

## BM-006

| 属性 | 值 |
|------|-----|
| 案例编号 | BM-006 |
| 分类 | borderline |
| 案由 | 买卖合同纠纷 |
| 关键异常 | A2 |
| 预期等级 | 中度异常 |

**摘要**：法院在认定货物质量是否合格时，跳过了鉴定环节直接以感官判断定案，但被告未在法定期限内申请鉴定。异常信号存在，但被告自身行为也构成举证妨碍。

**推理**：A2（事实认定跳跃）成立，但反向校验发现被告存在举证妨碍，净异常判定为存疑。双向审计后降级为中度异常。
