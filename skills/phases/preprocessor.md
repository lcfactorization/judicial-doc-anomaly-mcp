# 结构化预处理

## 任务
对输入的案件材料进行结构化预处理，提取以下信息：

## Phase 0：材料覆盖度评分与基础构建

1. **材料覆盖度评分**：计算已提交材料与理想材料集的覆盖比例
   - 必需材料（权重50%）：核心文书全文
   - 强烈推荐材料（权重30%）：起诉状/答辩状/证据清单/多阶段文书
   - 推荐材料（权重20%）：庭审笔录/程序性裁定/时间线材料/背景信息
   - 覆盖度 = (已有材料权重之和 / 全部材料权重之和) × 100

2. **案件时间轴构建**：提取所有带时间戳的事件，构建全局时间线

3. **证据索引构建**：为每份证据分配唯一编号，建立证据属性表
   - 证据编号、类型、提交方、证明对象、质证情况、采信情况

4. **主张映射表构建**：提取起诉状/答辩状中的核心主张，建立主张ID

## Phase 1：信息解析与背景建构

1. 提取案件基本信息（案号、当事人、案由、裁判结果）
2. 提取争议焦点、事实认定、证据清单、法律适用等核心内容
3. 提取用户提供的背景信息（地域、时间、人际网络等）作为上下文约束
4. 若材料不足，记录缺失项

## 输出要求
输出JSON格式的结构化数据，包含：
- case_info: 案件基本信息
- completeness_score: 材料覆盖度评分
- timeline: 案件时间轴
- evidence_index: 证据索引
- claims_map: 主张映射表
- missing_items: 缺失项清单
