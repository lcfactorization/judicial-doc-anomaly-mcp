# 输出格式规范

## 维度检测结果格式
每个维度的检测结果必须包含以下字段：

### 通用异常项格式
- **异常项名称**
- **具体表现**（引用原文段落，标注页码/段落/行号）
- **指向获益方**（原告/被告/双方/无）
- **异常程度**（疑似/可能/高度可能/确定）
- **法理分析**（引用具体法条）
- **A系列分类编号**（A1-A8）
- **反向校验结果**
- **净异常判定**（成立/存疑/不成立）

### 事实认定维度特殊格式
- **编号**（F-01至F-26）
- **异常表现**（引用原文段落+证据编号）
- **翻案权重**（★数量）
- **异常程度**（疑似/可能/高度可能/确定）
- **法理分析**

### 耦合分析格式
- **耦合等级**（弱/中/强/结构性偏差）
- **触发维度及异常项**
- **指向获益方**
- **综合风险评级**

## 报告模板变量
报告生成时使用以下变量替换：

| 变量 | 说明 |
|------|------|
| `{{report_id}}` | 报告编号 |
| `{{case_name}}` | 案件名称 |
| `{{doc_type}}` | 文书类型 |
| `{{detection_time}}` | 检测时间 |
| `{{model_name}}` | 分析模型 |
| `{{completeness_score}}` | 材料完整性评分 |
| `{{version}}` | 引擎版本 |
| `{{risk_level}}` | 综合异常等级 |
| `{{risk_reason}}` | 风险原因 |
| `{{anomaly_table}}` | 异常总览表 |
| `{{dimension_details}}` | 分维度详情 |
| `{{adversarial_table}}` | 对抗校验汇总 |
| `{{coupling_analysis}}` | 耦合分析 |
| `{{quality_score_table}}` | 质量评估 |
| `{{quick_check_results}}` | 翻案速查结果 |
| `{{remedies}}` | 救济路径建议 |
