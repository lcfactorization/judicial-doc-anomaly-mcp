# 维度八：逻辑闭环与推理链条

## 检测逻辑
审查裁判文书的推理链条是否完整，是否存在逻辑跳跃、自相矛盾或说理断裂。

## 检测项（6项）
1. **诉请与裁判脱节**：裁判结果未回应当事人的核心诉请
2. **说理与主文脱节**：本院认为部分与判决主文不一致
3. **推理跳跃**：从事实直接跳到结论，缺少中间推理环节
4. **自相矛盾**：判决书内部存在逻辑冲突
5. **前提-推理-结论链条断裂**：大前提（法律规范）是否正确；小前提（事实认定）是否成立；推理过程是否有效；结论是否从前提必然得出
6. **内部一致性**：文书各部分的逻辑是否自洽；例外情况是否被合理处理
