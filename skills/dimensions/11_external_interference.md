# 维度十一：外部干预与背景关联

## 检测逻辑
审查是否存在异常的裁判倾向与当事人背景关联，是否存在利益冲突迹象。

## 检测项（3项）
1. **异常倾向**：裁判倾向是否与案件证据强度不匹配；是否存在对特定当事人的不当优待；裁判思路是否突然转变
2. **背景关联**：当事人社会背景是否影响裁判；是否存在利益冲突迹象；代理律师与审判人员关系是否合规
3. **人际网络异常**：办案人员与代理人的既往执业交集；涉案实体之间的公开互动与网络关系
