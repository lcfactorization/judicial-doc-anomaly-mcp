# 维度十五：类案偏离量化

## 检测逻辑
将本案裁判结果与同辖区、同类案件的通常裁判标准进行量化比较。

## 偏离度计算模型
Deviation Score = |本案裁判结果值 - 类案裁判结果均值| / 类案裁判结果标准差

## 结果值映射规则
- 对于赔偿金额、罚金数额等连续变量：直接使用数值
- 对于责任比例：映射为0-1之间的比例值
- 对于定性结果（支持/驳回）：构建支持率指标

## 偏离度判定标准
| Deviation Score | 含义 | 信号等级 |
|---|---|---|
| < 0.5 | 完全位于正常波动范围内 | 无异常信号 |
| 0.5 ~ 1.0 | 位于正常波动边缘 | 弱异常信号 |
| 1.0 ~ 2.0 | 显著偏离类案均值 | 中度异常信号 |
| > 2.0 | 极端偏离，超出95%置信区间 | 高度异常信号 |

## 类案检索要求
- 检索范围：同省/直辖市近5年同类案由裁判文书
- 最低样本量：不少于10件
- 排除条件：明显不同事实基础或法律争议焦点的案件
- 加权考虑：指导性案例、公报案例的权重高于普通案例

## 检测项（4项）
1. **支持率偏离**：本案支持率与类案平均支持率的偏差
2. **金额偏离**：本案裁判金额与类案平均金额的偏差
3. **责任比例偏离**：本案责任划分与类案惯例的偏差
4. **法律适用偏离**：本案适用的法律规则与类案主流观点的偏差
