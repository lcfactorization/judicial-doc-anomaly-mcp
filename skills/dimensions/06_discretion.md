# 维度六：自由裁量权行使

## 检测逻辑
审查自由裁量权的行使是否超出合理范围，是否违背比例原则或同类案件惯例。

## 检测项（6项）
1. **赔偿金额畸高/畸低**：裁判确定的赔偿金额显著偏离同类案件标准
2. **责任比例失衡**：多方责任划分明显不合理
3. **违约金调整不当**：对违约金的调整缺乏合理依据
4. **利息/滞纳金计算错误**：计算方式或起算时间有误
5. **裁量理由缺失**：从轻/从重是否有法定情节支撑；裁量考量因素是否完整
6. **不当考量因素**：是否存在不应纳入裁量考量范围的因素
