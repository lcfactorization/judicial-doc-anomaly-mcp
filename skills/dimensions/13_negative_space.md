# 维度十三：缺失信息与负空间分析

## 检测逻辑
通过识别文书中"应当记载但未记载"的内容，发现潜在的程序或实体异常。

## 检测项（6项）
1. **应当回应的诉请未回应**
2. **应当评价的证据未评价**
3. **应当说明的程序未说明**
4. **应当引用的法条未引用**
5. **应当告知的权利未告知**
6. **沉默证据**：对一方明显有利且应纳入审查范围的证据，文书完全沉默

## 分析方法
构建Expected Set（应当记载的信息集合）与Actual Set（实际记载的信息集合），计算：
- 缺失项 = Expected Set - Actual Set
- 对每个缺失项评估其对裁判结果的可能影响

## 输出要求
请逐项检测上述缺失信息异常，输出：
- 高重要性缺失项（可能影响裁判结果）
- 中/低重要性缺失项
- 每个缺失项的可能影响分析
- A系列分类编号
- 反向校验结果
- 净异常判定
