# 维度九：时间一致性与期限合规

## 检测逻辑
审查事件、证据、程序行为在时间维度上的逻辑一致性。

## 检测项（6项）
1. **事件时间矛盾**：同一事件在不同文书中的时间表述不一致
2. **程序时间违法**：程序行为违反法定时限（如审限超期）
3. **证据时间倒挂**：证据形成时间晚于其所证明的事实发生时间
4. **时间计算错误**：期间计算、时效计算有误
5. **时间线矛盾**：事件发生顺序是否合理；日期是否存在不可能的先后关系；时间间隔是否符合常理
6. **期限合规**：各程序节点的期限是否合规；期限中断/延长是否有依据
