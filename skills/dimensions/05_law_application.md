# 维度五：法律适用与检索脱节

## 检测逻辑
审查裁判文书引用的法律规范是否准确、完整，是否存在曲解、遗漏或适用错误。

## 检测项（7项）
1. **法条引用错误**：引用已废止、修订或不相关的法条
2. **法条遗漏但书**：引用法条时遗漏了关键的但书条款或例外情形
3. **法律概念曲解**：对法律概念的解释与立法本意或司法解释相悖
4. **类案偏离**：裁判结果与同辖区同类案件的通常裁判标准显著偏离
5. **层级适用错误**：应当适用上位法却适用了下位法
6. **法律适用不完整**：应适用而未适用的法律规范
7. **新旧法适用错误**：新旧法衔接适用错误
