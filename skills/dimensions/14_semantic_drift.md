# 维度十四：语义漂移与概念偷换

## 检测逻辑
识别从原始材料到裁判文书之间的法律概念替换与描述弱化。

## 检测项（5项）
1. **概念替换**：将起诉状中的法律概念替换为不同含义的概念（如将"违法解除"替换为"协商解除"）
2. **描述弱化**：对一方主张的描述使用弱化、模糊的措辞（如将"明确拒绝"弱化为"未明确同意"）
3. **焦点偏移**：实际审理的争议焦点与起诉状/答辩状不一致
4. **定性改变**：对同一行为的法律定性在文书间发生变化
5. **术语一致性**：同一概念在不同段落含义变化；关键术语定义不一致
